Skripte — freigegebene Sammlung des Clusters

Die Skripte liegen im GitHub-Repository. Diese Seite liest die Liste skripte.json und zeigt Titel, Kurzbeschreibung, Typ, Datum, Status und den Link. Ansehen und Herunterladen öffnet GitHub — Änderungen laufen über den Freigabeprozess (Pull Request).

  1. Skript-Datei im Ordner skripte/ des Repositorys hochladen.
  2. In skripte.json einen Eintrag ergänzen (Titel, Kurztext, Typ, Pfad).
  3. Als Pull Request einreichen — Ebene 2 prüft, Ebene 3 schaltet frei.
  4. Nach dem Merge erscheint der Eintrag hier automatisch.
